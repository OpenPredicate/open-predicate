# Brand assets

| File | Use |
| --- | --- |
| [`logo.svg`](./logo.svg) | The mark. Primary logo; carries its own background, so it works on any surface. |
| [`logo-512.png`](./logo-512.png) · [`logo-192.png`](./logo-192.png) · [`logo-64.png`](./logo-64.png) | Raster mark, for avatars, favicons and anywhere SVG is not accepted. |
| [`logo-wordmark.svg`](./logo-wordmark.svg) | Mark plus wordmark, for light backgrounds. |
| [`logo-wordmark-dark.svg`](./logo-wordmark-dark.svg) | Mark plus wordmark, for dark backgrounds. |

The mark is `{ > }` — JSON braces around a comparison, which is what the language is: a predicate,
JSON-encoded, SQL-flavoured.

| Colour | Hex | Role |
| --- | --- | --- |
| Ink | `#0F172A` | Mark background, wordmark text on light |
| Sky | `#38BDF8` | Braces, wordmark accent on dark |
| Sky (deep) | `#0284C7` | Wordmark accent on light |
| Paper | `#F8FAFC` | The chevron, wordmark text on dark |

Clear space around the mark should be at least the corner radius. Do not recolour the mark, stretch
it, or place the wordmark's two halves in one colour — the `Open`/`Predicate` split is the wordmark.
